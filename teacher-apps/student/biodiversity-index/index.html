📐 公式说明

香农指数：H' = -Σ(pi × ln(pi))

辛普森指数：D = 1 - Σ(pi²)

其中 pi = 该物种个体数 / 总个体数

📚 指数解读指南

🟢 香农指数 (H') 解读

  • H' < 1：多样性低
  • H' 1-2：中等多样性
  • H' 2-3：较高多样性
  • H' > 3：高度多样性

🔵 辛普森指数 (D) 解读

  • D < 0.3：多样性低
  • D 0.3-0.5：中等多样性
  • D 0.5-0.7：较高多样性
  • D > 0.7：高多样性

🟡 影响因素

  • 栖息地破坏 → 指数降低
  • 气候变化 → 影响分布
  • 外来物种入侵 → 降低本土多样性
  • 保护措施 → 有助于恢复
