# 创意网页工坊

收录和展示优秀的网页应用作品，支持教师和学生作品展示，欢迎各校投稿！

## 功能特点

- 🎨 作品展示 - 精美的卡片式展示界面
- 🏫 双轨分类 - 教师作品 / 学生作品
- 🔍 智能搜索 - 支持按标签、类型、学校搜索
- ⭐ 互动功能 - 点赞、收藏、评论
- 📝 开放投稿 - GitHub Issue/PR 提交审核

## 快速开始

```bash
# 本地预览
bundle install
bundle exec jekyll serve

# 访问 http://localhost:4000
```

## 投稿方式

1. Fork 本仓库
2. 在 `_data/apps.yml` 添加作品信息
3. 提交 Pull Request
4. 审核通过后自动发布

详细指南：[投稿说明](https://linqdsf.github.io/class-web-gallery/submit/)

## 技术栈

- Jekyll 静态网站生成器
- GitHub Pages 免费托管
- GitHub Actions 自动部署
- Giscus 评论区
