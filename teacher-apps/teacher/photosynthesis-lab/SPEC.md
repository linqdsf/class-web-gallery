# 虚拟光合作用实验平台 - 设计规范

## 1. 概念与愿景

一个沉浸式的虚拟植物实验室，让用户通过调节光照强度和CO₂浓度，实时观察光合作用速率的变化。界面融合科学仪器的精密感与现代数据可视化的优雅，传达"探索自然奥秘"的实验精神。

## 2. 设计语言

### 美学方向
科学实验室风格 — 深色背景模拟实验室环境，搭配荧光绿和琥珀色强调色，营造专业实验氛围。

### 色彩方案
- 主色: `#1a2f1a` (深绿实验室)
- 次色: `#2d4a2d` (植物绿)
- 强调色: `#4ade80` (荧光绿/光合绿)
- 辅助色: `#f59e0b` (琥珀/光能)
- 背景: `#0f1a0f` (极深绿)
- 文字: `#e2e8f0` (浅灰白)
- 卡片: `#1e3a1e` (深绿卡片)

### 字体
- 标题: "Orbitron", monospace (科技感)
- 正文: "Inter", sans-serif
- 数据: "JetBrains Mono", monospace

### 动效哲学
- 参数调节: 平滑过渡 200ms ease-out
- 图表更新: 实时绘制，60fps 流畅动画
- 植物动画: 气泡上升、光合作用脉冲效果
- 交互反馈: 按钮点击波纹、滑动条拖拽高亮

## 4. 功能与交互

### 核心功能

#### 4.1 光照强度控制
- 范围: 0 - 1000 μmol/m²/s (微摩尔光子每平方米每秒)
- 滑块 + 数值输入
- 对应真实自然光: 阴天200 / 晴天800 / 强光1200
- 视觉反馈: 背景亮度变化、植物受光面积

#### 4.2 CO₂浓度控制
- 范围: 200 - 2000 ppm
- 滑块 + 数值输入
- 对应真实场景: 大气400 / 温室800 / 高浓度1500
- 视觉反馈: CO₂分子动画密度变化

#### 4.3 光合作用速率计算
基于米氏方程模型：
```
Rate = (Vmax × [CO2] × I) / (Km_CO2 × Km_I + Km_CO2 × I + Km_I × [CO2] + [CO2] × I)
```
参数：
- Vmax = 100 (最大速率)
- Km_CO2 = 300 (CO₂半饱和常数)
- Km_I = 400 (光照半饱和常数)

#### 4.4 动态图表
- X轴: 时间 (秒)
- Y轴: 光合作用速率 (μmol/m²/s CO₂固定)
- 实时绘制曲线
- 显示当前速率数值
- 保存最近60秒数据

### 交互细节

#### 滑块拖拽
- 拖动时显示实时数值气泡
- 松开平滑过渡到新值
- 键盘方向键微调 (±1单位)

#### 植物可视化
- 根据光照强度变化叶片颜色深浅
- CO₂浓度影响气泡产生速度
- 持续的O₂气泡上升动画

#### 数据记录
- 自动记录每次调整的时间戳和数值
- 可导出为CSV格式

## 5. 组件清单

### 控制滑块
- 默认: 深绿轨道，荧光绿滑块
- 悬停: 滑块放大1.1x，轨道发光
- 拖拽: 滑块脉冲动画，显示当前值
- 禁用: 灰色，降低透明度

### 数据显示卡片
- 实时更新的数字使用等宽字体
- 数值变化时短暂高亮动画
- 单位标签较小灰色

### 植物SVG
- 多层叶片叠加
- 茎干渐变
- 根部分布
- 气泡粒子系统

### 图表组件
- 响应式尺寸
- 网格线半透明
- 曲线渐变填充
- 坐标轴标签

### 按钮
- 默认: 深绿背景，荧光绿边框
- 悬停: 背景变亮，边框发光
- 点击: 波纹扩散效果
- 禁用: 降低透明度

## 6. 技术方案

### 架构
- 单文件 HTML (便于嵌入网站)
- 原生 JavaScript (无框架依赖)
- CSS3 动画 + requestAnimationFrame

### 关键实现
- Canvas 绘制动态图表
- CSS 变量控制主题
- localStorage 保存用户设置
- Web Animations API 处理复杂动画

### 响应式断点
- 桌面: >768px (双栏布局)
- 移动: ≤768px (单栏垂直布局)

### 性能目标
- 60fps 动画
- <100ms 输入响应
- 首屏加载 <2秒
